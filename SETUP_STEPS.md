# One-time GitHub setup

1. On github.com click **New repository**. Name: `pdc-gpu-ids-mlp`. Select **Public**.
   Do NOT add a README, .gitignore or license (they already exist here).
2. In Git Bash inside this folder run: `bash setup_git.sh https://github.com/<username>/pdc-gpu-ids-mlp.git`
   (this commits, creates the `develop` branch, tags `v0.0-scope` and pushes everything).
3. Copy the repository URL into the scope pack and submit it with the PDF.
4. Delete this file after setup if you want a cleaner repo.
